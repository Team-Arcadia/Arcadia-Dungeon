Arcadia Dungeon v1.1 - Recette de concordance admin et joueur

Objectif : tester Arcadia Dungeon v1.1 candidate comme le ferait un admin non dev : UI, logique, sauvegarde, erreurs, run, HUD, inventaire et multi.

Les features marquees placeholder doivent annoncer clairement qu'elles ne sont pas disponibles et ne doivent pas modifier les donnees serveur.

Le testeur ne doit utiliser que le jeu. Il ne doit pas lire ou modifier les fichiers JSON/config/base de donnees.

Version cible : Arcadia Dungeon v1.1 candidate - Minecraft 1.21.1 - NeoForge 21.1.222 - TesseraUI 1.1 - JAR attendu : arcadia_dungeon-1.1.0.jar.

0 / 0 tests renseignes

Regles de test

Important : le testeur ne doit pas ouvrir les dossiers du mod, les fichiers JSON, la base de donnees ou les logs pendant le test. Tout doit passer par le jeu.

Acces autorises

  • Commandes Minecraft si le testeur est OP.
  • Menu admin via /arcadia admin.
  • Hub joueur via la touche H.
  • Screenshots et notes de bug.

Bloquant release

  • Crash client ou serveur.
  • Crash SQLite au demarrage serveur : le JAR distribue doit embarquer le driver.
  • Impossible de creer, sauvegarder ou lancer un donjon.
  • Instance qui ne se reset pas ou qui bloque le relaunch.
  • Inventaire joueur perdu ou melange avec l'inventaire donjon.
  • Deux joueurs qui lancent le meme donjon se retrouvent dans des instances differentes.
  • UI inutilisable : texte coupe, bouton hors ecran, champ impossible a remplir.

Export du resultat

  • Utiliser Exporter JSON en haut de page a la fin du test.
  • Si le navigateur bloque le telechargement, utiliser Copier JSON puis coller le contenu dans Discord.
  • Le JSON contient les metadonnees, le statut de chaque etape, les commentaires, bugs et verdict.

Definition d'un test reussi

  • Chaque fonctionnalite visible dans l'UI a ete cliquee au moins une fois.
  • Chaque ecran admin et joueur a ete ouvert dans un etat vide puis avec des donnees.
  • Les valeurs sauvegardees sont encore presentes apres fermeture/reouverture du menu.
  • Les actions sensibles affichent un retour clair : toast, message, etat visible ou resultat en jeu.
  • Les erreurs utilisateur sont comprehensibles et ne cassent pas le menu.
  • Une run complete victoire, une defaite/abandon et un relaunch du meme donjon ont ete testes.

Ce qu'il faut noter comme bug

  • Texte coupe, superpose, hors ecran, trop sombre ou illisible.
  • Bouton sans effet visible.
  • Sauvegarde qui semble marcher mais ne persiste pas.
  • Champ qui refuse une valeur valide ou accepte une valeur dangereuse sans message.
  • Run fantome, slot bloque, HUD qui reste apres fin de run.
  • Inventaire normal perdu ou inventaire donjon incoherent.
